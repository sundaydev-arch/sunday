# Security Policy

## Supported versions

This repository tracks `main`. Please report issues against the latest commit.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

Email: open a private GitHub Security Advisory on this repository once it is published, or contact the maintainer via the GitHub profile linked from the site.

Include:

- Impact and affected paths
- Steps to reproduce
- Suggested fix if you have one

We will acknowledge reports as soon as possible and coordinate a fix before any public disclosure.
